## Using an archive

Extract one team's archive into a separate working copy of the challenge repository, retaining the `Project_5/` directory layout. Read its `SUBMISSION.md` and implementation instructions. Obtain the [Stage 1](../releases/problem7_student_start.zip?raw=true) and [Stage 2](../releases/problem7_student_final.zip?raw=true) datasets separately and extract them at the paths the team's instructions require. The archives omit duplicate organizer datasets and introductory material, which remain available in this repository. No team code was executed as part of archiving.

## Snapshot notes

- **Two Braincells:** the main answer CSVs are the scored submission. The included `qwen_3b_trial/` is an unscored Stage 1 experiment.
- **No Plan is a plan:** both Python and R implementations are included. The canonical scored answer pair is directly under `Project_5/`; implementation-specific answer copies are supporting files. The compiled C# executable is omitted; its source and build instructions are retained.
- **SK²:** Stage 1 answers are included. No Stage 2 answer CSV was present in the reviewed snapshot. Stage 2 code or logs do not constitute a final answer submission.

Team-authored reports and slides retain their original wording. Later organizer decisions, including coding-assistant exceptions and the +40 bonuses for Two Braincells and SK², are recorded in the results sheet rather than retroactively changing the submissions.
